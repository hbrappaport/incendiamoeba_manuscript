Analysis code for biophysical properties. Please note that predicted AlphaFold sturctures are available at: [https://doi.org/10.6084/m9.figshare.32254887](https://doi.org/10.6084/m9.figshare.32254887)

Content includes: 

  1_analyze_pdb_structures: Processing scripts and csvs of biophysical properties for identified ortholog pairs
  
  2_plot_parameters: plotting scripts for Fig. 4F and Fig. S8 
  
  3_protein_visualization: Script to visualize and align orthologs in PyMol via the command line.  To install pymol, use 'conda install -c conda-forge pymol-open-source'
  
  4_Tm_analysis: Tm predictions for I. cascadensis and V. vermiformis in allTms.csv, plotting script for Fig. 4D
